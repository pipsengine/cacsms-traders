# UI/UX foundation

The application is light-first: white cards, soft neutral canvas, charcoal/navy typography, restrained blue primary accent, green success, amber warning and red destructive states. No dark dashboard surfaces are used.

Pages share one application shell, spacing scale, typography, buttons, status chips, cards, forms, tables, drawers and modal patterns. Desktop trading workstations are primary; laptop widths remain usable. Empty/loading/error states are first-class.
