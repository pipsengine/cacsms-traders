# Calculation specification
Pair evidence uses volatility-normalized log return over the configured closed-candle window. A base currency receives the pair score and the quote receives its inverse. Currency values are cross-sectionally centered so the eight-currency universe is relative rather than absolute. Historical snapshots derive slope, velocity, acceleration and persistence. Pair relationship gap is base strength minus quote strength. Relationship state uses gap magnitude plus its temporal change: EQUILIBRIUM for close values, DIVERGENCE for expanding separation, CONVERGENCE for compressing separation, ROTATION for leadership crossover, TRANSITIONING for fast movement around equilibrium, otherwise UNCERTAIN. Thresholds are configuration candidates and must be validated before production use.
